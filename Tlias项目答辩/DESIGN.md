# DESIGN.md · Tlias 项目答辩 PPT 视觉设计

风格代号：**课程 PPT 家底风格**。色板与字体直接取自用户自有的 Java 课程课件（主题色 `363C3B / 4F81BD / AD2B26 / FFFFE4`），保证与既有教学资料同源；界面截图则为 Tlias 系统真实运行界面。

## 1. 画布与母版

- 画布：**1280 × 720**（16:9，与用户既有课件一致）
- 页面 padding：左右 64px
- 母版（内容页 02–14 统一遵守）：

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :-- | :-- | :-- | :-- |
| **A · 标题块** | 0–120px | 120px | 左上角主标题 27px bold（`#363C3B`），下方副标 13.5px（`#6E7372`）一行；**不设色条、不放装饰**（对齐课件风格） |
| **B · 内容区** | 124–646px | 522px | 全部正文/图/卡片，禁止越界 |
| **C · 页脚条** | 674–692px | 18px | 左：项目名 10.5px `#A8ADAC`；右：页码 `NN / 15` 10.5px `#A8ADAC`；**无分隔线** |

- 封面（01）、结束页（15）采用自定义极简版式：白底 + 左侧 8px 砖红竖条 + 标题 + 落款。
- 封面按用户明确要求「干净整洁、不需要太多东西」：**不放证件照、不放界面截图、不放数据块、不加副标题以外的装饰**，仅保留标签 / 主标题 / 副标题 / 落款四类元素。

## 2. 颜色系统

色彩池（4 hex，硬上限）：

| 角色 | HEX | 用途 |
| :-- | :-- | :-- |
| **主色** | `#363C3B` | 墨绿灰：标题、深色块、代码块底、结论条 |
| **辅色** | `#4F81BD` | 蓝：图标、流程箭头、分隔竖条、进度条 |
| **强调色** | `#AD2B26` | 砖红：巨型数字、序号、焦点标注、结论条竖条 |
| **文本主色** | `#1A1A1A` | 正文文字 |

中性色（剩余部分）：背景 `#FFFFFF`、结论条底 `#FCFAEE`、代码块前景 `#F0ECD6`、分隔线 `#E3E0CE`、次要文字 `#6E7372`、页脚 `#A8ADAC`。

### 2.1 标志性元素：米黄结论条
课件中最鲜明的语言是「结论条」：浅米黄底 + 左侧砖红竖条 + 正文。PPT 每张信息量大的页面底部都有一条，用于承载「所以呢」判断句。已用于 P03 / P05 / P06 / P08 / P11 / P12 / P14。

### 2.2 色彩面积分配（逐页）

| 页面类型 | 主色 | 辅色 | 强调色 | 备注 |
| :-- | :-- | :-- | :-- | :-- |
| Hero（01/09/15） | 30–45% | 8–12% | 8–14% | 封面/结束页以留白为主，砖红竖条与文字构成唯一焦点 |
| Supporting（其余） | 20–35% | 8–16% | ≤ 6% | 强调色严格克制，仅用于序号/巨型数字/竖条 |
| 深色页（06/08/12） | 45–60% | 8–12% | 6–10% | 代码块与侧栏用主色块，与其它页比例显著不同 |

### 2.3 渐变与半透明
全篇**不使用渐变**（课件风格为纯平色块）。仅用：`#FCFAEE` 结论条底、`#FFFFFF` 卡片底、0.75pt `#E3E0CE` 描边。

## 3. 字体系统

字体家族（2 套）：
- **无衬线**：`Microsoft YaHei`（微软雅黑）— 标题 bold / 正文 regular
- **等宽**：`Consolas` — 代码片段、接口路径、序号

> 说明：用户课件主题字体为「阿里巴巴普惠体 + Fira Code」，但本机 `C:\Windows\Fonts` 中**未安装**这两款字体（已核实），若直接引用会回退为系统默认字体、破坏排版一致性。故选用本机已装且气质最接近的等价组合：**微软雅黑（几何无衬线，替代阿里普惠体）+ Consolas（等宽，替代 Fira Code）**。若后续安装阿里普惠体，只需替换 DESIGN.md 与 build_ppt.py 中的 FONT 常量即可全局换字体。

| 层级 | 字号 | 字重 | 行高 | 用途 |
| :-- | :-- | :-- | :-- | :-- |
| 封面主标题 | 48px | bold | 1.15 | 仅第 01 页 |
| 结束页金句 | 34px | bold | 1.45 | 仅第 15 页 |
| 巨型锚点数字 | 38–72px | bold | 1.0 | 第 05 / 11 / 12 / 14 页 |
| 页面主标题 | 27px | bold | 1.2 | 每页 A 区固定 |
| 副标题 | 13.5px | regular | 1.3 | A 区副标 |

| 代码 / 路径 | 10.5–11.5px | regular | 1.3–1.45 | Consolas 代码块与接口路径 |
| 页脚 / 页码 | 10.5px | regular | 1.2 | C 区 |

## 4. 密度门禁

- 常规内容页留白 ≤ 35%；封面/结束页 ≤ 45%。
- 每页至少 1 个视觉锚点：巨型数字（≥48px）、主视觉图（占 B 区 ≥ 30%）或大色块。
- 卡片填充率 ≥ 85%；同排卡片尾部元素 y 轴对齐（差值 ≤ 16px）。
- 单页图片 ≤ 3 张，图片总面积 ≤ 内容区 60%。

## 7. 逐页自检（提交前必须满足）
1. A/B/C 三区齐全，页码 `NN / 15` 位置全篇一致（C 区右下）。
2. 标题块右侧不放装饰小图。
3. L1 主视觉占 B 区 ≥ 30%（04/07/08/09/13 逐页核对）。
4. 色彩池仅 4 hex，字体仅 2 套家族。
5. 相邻页版式不重复；本页与上页视觉重量有明显差异。
6. 每页 ≥ 1 个视觉锚点（≥44px 元素或 ≥40% B 区面积图）。
7. 留白 ≤ 35%（封面/结束页 ≤ 45%）。
8. 关键数据后必有判断句。
